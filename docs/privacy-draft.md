# プライバシーポリシー

詐欺ブロッカー（以下「本アプリ」）は、株式会社RE-X（以下「当社」）が提供します。本アプリが扱う情報と、その使い方を説明します。

## 1. 端末の中だけで扱い、送らない情報

- 電話帳：電話帳にない番号からの着信かどうかを判断するために、端末の中で照らし合わせます。電話帳の中身は送りません。
- 着信の履歴（本アプリが判定した着信）：端末の中に保存します。
- 「この画面を調べる」で撮った画面と、読み取った文字：端末の中で読み取り、画像は保存しません。
- 「コピーした文字を調べる」「共有」で受け取った文字：端末の中で調べます。
- 相談する家族の電話番号：端末の中に保存します。

## 2. 当社のサーバーに送る情報

| 情報 | 使い道 | 保存の期間 |
| --- | --- | --- |
| 接続しようとしたサイトのドメイン名（DNS の問い合わせ） | 危険なサイト・広告への接続を止めるための判定 | 判定のためだけに使い、ドメイン名と端末を結びつけて保存しません |
| 調べたリンクのドメイン名 | できたばかりのサイトかどうかの確認 | 登録日の結果を 1 日だけ保存します（端末の情報は含みません） |
| 報告された迷惑電話の番号と分類 | 迷惑電話データベースの作成 | 報告した端末は、元に戻せない形（ハッシュ）でだけ記録します |
| 電話の傾向（この 30 日に止めた・注意した電話の、分類ごとの件数） | 「ほかの方と比べた傾向」の表示 | 番号は送りません。端末ごとに最新の件数だけを保存します |
| ブロックした番号と設定（同期を使うとき） | 機種変更・複数端末での引き継ぎ | 端末で暗号化してから送り、当社は中身を読めません。「同期をやめる」で削除します |

## 3. 家族の見守りを使うとき

家族の見守りに加わると、次の情報が同じ家族の端末と、当社のサーバーで共有されます。当社の運営担当者が、不具合の調査やサポートのために見ることがあります。

- 端末の呼び名・機種名・役割（管理者・見守られる端末）・保護をしているか
- 今週止めた電話・サイトの数、訓練の結果
- 家族の履歴：止めた電話（番号を含む）・危険なサイトを止めたこと・電話のあとの「お金の話が出た」・登録した番号など。30 日分を保存します
- 家族で止める迷惑電話の番号とメモ（暗号化して保存します）

## 4. 第三者への提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません。サーバーには Cloudflare, Inc. のサービスを使います。画面の文字の読み取りには、端末の中で動く Google の ML Kit を使います（画像は送りません）。

## 5. 削除

アプリの「同期をやめる」「この端末を家族から外す」で、サーバーの対応する情報を削除できます。そのほかの削除のご依頼は、サポートの窓口へご連絡ください。
